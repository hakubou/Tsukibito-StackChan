# 全体構想

## コンセプト
歌合の場で句を書き留め、届ける付き人。来場者の一句を受け取り、**縦書きの短冊**にして手渡す。

## 体験の流れ（30秒以内）
1. ゲームで一句が決まる → ロボットへ送信
2. 顔を上げて「をかし！」などと反応
3. 句を読み上げる（区切りごとに小さく頷く）
4. 首を文机の方へ向け「したためております…」→ 文机から短冊がせり上がる
5. 正面に向き直ってお辞儀「どうぞ、お納めくださいませ」

## 構成
```
[ゲーム側PC/スマホ] --WiFi(HTTP)--> [CoreS3] --BLE--> [S1プリンタ（文机の中）]
                                       ├─ SCS0009×2（首：パン/チルト）
                                       ├─ スピーカー（セリフ・読み上げ）
                                       ├─ 近接センサ（来客検知）
                                       └─ microSD（句リスト・音声）
```
- 句の入力: ① HTTP API `POST /print`　② スマホ用入力フォーム（保険）　③ おみくじモード（SDの句リスト）
- 短冊はCoreS3側で 384px 幅の白黒画像として描画（明朝体・縦書き）して送る
- 会場WiFiに頼らずオフラインで完結（テザリング or CoreS3 をAP化）

## 開発ステップ
| Step | 内容 | 完了条件 |
|---|---|---|
| 0 | S1 の BLE プロトコル解析（PC から画像印刷） | PC から任意画像が出る |
| 1 | CoreS3 から BLE で固定画像を印刷 | ボタン1つで紙が出る |
| 2 | 縦書き短冊の描画・印刷 | 短冊が完成 |
| 3 | HTTP API ＋ スマホ入力画面 | スマホから印刷 |
| 4 | 演出（顔・セリフ・首の動き） | 一連の流れが通る |
| 5 | 装飾の製作（decoration.md） | 見た目完成 |
| 6 | イベント向け強化（再接続・紙切れ・電池） | 半日連続稼働 |

外装（Step 5）はプリンタの実寸さえ決まれば Step 0 と並行して進められる。
