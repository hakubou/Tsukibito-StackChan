首サーボ（SCS0009×2）のブレッドボード配線
コンデンサあり版

CoreS3 の Port A（Grove・赤いポート）の4本だけでつなぐ版。部品は 1kΩ 抵抗1本と 電解コンデンサ 100µF／16V ×2。（コンデンサなしで組む場合は こちら）ファームウェアは src/Neck.h（TX=G2、RX=G1）。

Grove の端子をブレッドボードに挿すには、Grove → ジャンパーワイヤ（オス）変換ケーブルを使う。

回路図

 Port A G2 (TX, 黄) ──[R1 1kΩ]──┬──────────┬──── SIG ─ J1 サーボ1（首の左右, ID 1）
                                 │          └──── SIG ─ J2 サーボ2（首の上下, ID 2）
 Port A G1 (RX, 白) ─────────────┘

 Port A 5V  (赤) ─────────────────┬──────┬──────── +5V ─ J1・J2
                                +[C1]  +[C2]  100µF／16V × 2（サーボ起動時の電圧低下対策）
 Port A GND (黒) ─────────────────┴──────┴──────── GND ─ J1・J2
  • CoreS3 が送信していないとき、G2 は 3.3V を出し続けている。これが R1 越しに SIG を 1（3.3V）に保つので、プルアップ抵抗やダイオードは要らない
  • サーボが返事をするときは、サーボが SIG を直接上げ下げし、G1 で受け取る。R1 は、CoreS3 とサーボが同時に信号を出したときに電流を制限する役
  • CoreS3 の送信は G1 にもそのまま返ってくる（エコー）ので、プログラムで読み捨てている
  • Port A には 3.3V のピンがない。R1 を 5V につないではいけない（G1 に 5V がかかる）

組む前の確認

  1. サーボのコネクタの向き：J1・J2 は左から GND／5V／SIG。サーボのケーブルの黒が GND（18・24列）に来るように挿す。5V は真ん中なので、逆に挿しても壊れにくいが動かない
  2. 黄と白を取り違えない：黄（G2）は R1 を通して 5列目へ、白（G1）は 9列目へ直接
  3. 電源を入れたら：首がゆっくり正面へ動く（起動時に 1.5 秒かける）ので、手で押さえないこと
電解コンデンサの向き（逆にすると破裂・発熱のおそれ）
・帯（白や灰色の帯に「−」が並んでいる側）がマイナス。こちらを 青い − レール（GND）へ
・長い足がプラス。こちらを 赤い ＋ レール（5V）へ
・挿したら、電源を入れる前にもう一度向きを確認する。電源を入れて、焦げ臭い・膨らむ・熱いと感じたらすぐに USB を抜く
・コンデンサはサーボの近く（J1・J2 のそば）に置くほど効く

コンデンサの選び方

項目内容
種類アルミ電解コンデンサ（リード線タイプ、極性あり）
容量100µF（220〜470µF でもよい。大きいほど電圧の落ち込みに強い）
耐圧16V（5V の回路なので 10V 以上なら可。6.3V は余裕がないので避ける）
数2個（サーボ1個につき1個）
本体の表示の例「100µF 16V」「100 16V」など。「105℃」とあるものは長持ち

コンデンサがあっても、首が速く動いたときに CoreS3 が再起動する場合は、サーボの ＋ レールを USB 充電器などの別の 5V から取り、GND だけ CoreS3 とつなぐ。
