組む前の確認

  1. ダイオードの向き：帯（カソード）を G17 側（5列目）に。逆にすると送信できない
  2. サーボのコネクタの向き：J1・J2 は左から GND／5V／SIG に並べた。サーボのケーブルの色（黒＝GND、赤＝5V）とピンの並びを見て、黒が GND（18・24列）に来るように挿す。5V は真ん中なので、逆に挿しても壊れにくいが動かない
  3. 3V3 と 5V を取り違えない：プルアップ（R1）は必ず 3V3 へ。5V につなぐと G18 に 5V がかかる
  4. 電源を入れる前に：サーボの首はゆっくり正面へ動く（起動時に1.5秒かける）ので、手で押さえないこと
コンデンサがないことへの対策
サーボが動き出す瞬間に電流が増え、CoreS3 が再起動することがある。ファームウェアでは、どんな動きにも最低 0.25 秒かけ、速さに上限（毎秒120°）を付け、起動時は2個をずらして動かしている。
それでも再起動する場合は、サーボの ＋ レールを USB 充電器などの別の 5V から取り、GND だけ CoreS3 とつなぐ（M-Bus の 5V はレールから外す）。
