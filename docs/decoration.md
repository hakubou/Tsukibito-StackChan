## 1. デザインの統一ルール

1. **色は3系統だけ**：調度品＝黒漆＋金、衣装＝松重（緑と紫）＋差し色の紅、紙と顔＝胡粉白（生成り）
2. **現代のモノは見せない**：プリンタの白い筐体、ケーブル、USB端子はすべて隠す
3. **ツヤは消す**：マットなフィラメントと布を使う。光沢のあるプラスチック感が出ると平安らしさが崩れる
4. **現代語の文字は1か所にまとめる**：案内文は屏風と高札だけに書く。本体まわりには置かない
5. **時代考証は「大和絵の雰囲気」が基準**：金屏風（桃山時代以降）など、時代がずれる記号は避ける

## 2. 文麿本体

全高の目安：足 10 ＋ 胴 55 ＋ 頭 55 ＋ 烏帽子 70 ≒ **約190mm**

### 2-1. 立烏帽子（たてえぼし）
| 項目 | 仕様 |
|---|---|
| 外形 | 幅 44 × 奥行 32 × 高さ 70mm（頭幅の約8割） |
| 形 | 縦長のドーム形。前面上部に「招（まねき）」と呼ばれる浅いくぼみ、表面に「さび」と呼ばれる細かいシワの凹凸を付ける |
| 材料 | 黒のマットPLA。壁厚 0.8〜1.0mm、中は空洞（インフィル 0%） |
| 重量 | **15g以下を厳守（目標 10g）**。SCS0009 は非力なので、お辞儀の後に頭が戻らなくなるのを防ぐ |
| 取付 | `hat_cat_CoreS3.stl` の CoreS3 への取付部（46×16mm）をそのまま使い、上に烏帽子の本体を載せる |
| 重心 | 頭の中心より**やや後ろ**に置き、お辞儀で前に倒れようとする力を小さくする |
| 飾り | 掛緒（かけお）：紫の組紐（φ2mm）を左右から垂らし、胸元で結ぶ |

### 2-2. 顔（M5Stack-Avatar のカスタム）
『源氏物語絵巻』の **引目鉤鼻（ひきめかぎばな）** を画面に落とし込む。画面サイズは 320×240。

| パーツ | 位置（中心 x,y） | 形・色 |
|---|---|---|
| 背景 | 全面 | 胡粉白 `#F3EEE3` |
| 置眉（おきまゆ） | (110, 58) / (210, 58) | 楕円 rx14・ry9、墨色 `#3A3A3A`。外側に薄い楕円を重ねてぼかし風にする |
| 引目（目） | y=118、x 88〜132 / 188〜232 | 太さ3px の線。わずかに下向きの弧 |
| 鉤鼻（鼻） | (160, 148) | 「く」の字の細い線（2px） |
| 口 | (160, 182) | 紅 `#B8343F` の小さな楕円 rx6・ry4。話すときは ry を 4→8 で口パク |
| 頬紅 | (92, 152) / (228, 152) | `#EFC3C0` の楕円 rx22・ry12 |

**表情と動きの一覧**
| 状態 | 目 | 口 | 首の動き | セリフ・演出 |
|---|---|---|---|---|
| 待機 | 引目。ときどきまばたき | 閉じる | 左右 ±10° をゆっくり見渡す | — |
| 御簾（無人が10分続いたとき） | — | — | 正面で止める | 画面の上から**御簾が降りて顔が隠れる**。近接センサが来客を検知したら御簾が上がる |
| 受領 | 細い楕円に少し開く | 「ま」の口 | 少し上を向く | 「をかし！」 |
| 読み上げ | 引目 | 口パク | 句の区切りごとに小さく頷く | 句を読み上げる |
| したため中 | 伏し目（線を下へ） | 閉じる | 文机の方へ約30°向く | 「したためております…」 |
| 献上 | 上向きの弧（笑み） | 閉じる | 正面に戻り、25° のお辞儀を1.5秒 | 「お納めくださいませ」＋鈴の音 |
| 紙切れ | 汗のしずくを表示 | への字 | 左右に小刻みに振る | 「あな…紙が尽きてしまいました」 |

- CoreS3 には近接センサ（LTR-553）が内蔵されているので、御簾の上げ下げは追加部品なしで作れる
- 顔は**画面の中央寄り**にまとめる。画面の端は烏帽子の縁や衣装の襟に隠れる可能性があるため

### 2-3. 装束（狩衣一式）
重ね着の順（内側から）：

| 層 | 名前 | 色 | 見え方・作り方 |
|---|---|---|---|
| 1 | 単（ひとえ） | 紅 | 襟元と袖口から 1〜2mm だけ覗かせる。実際は細い布を縁に貼るだけでよい |
| 2 | 狩衣（かりぎぬ） | 表：緑／裏：紫 | 丸い襟（盤領）。**袖は後ろ身頃にだけ付いていて、肩の前側が開いている**のが狩衣の特徴。その隙間から紅の単が見えるようにする |
| 3 | 袖括り（そでくくり）の緒 | 白か紫の細紐 | 袖口に通して絞り、房を垂らす |
| 4 | 当帯（あておび） | 表地と同じ布 | 腰に幅5mmの帯 |
| 5 | 指貫（さしぬき） | 紫 | ふくらんだ袴。**足（feet）と胴の下部を覆い隠す**スカート状に作る |

**作り方**
- **肩ヨーク（3Dプリント）**：胴のシェルに固定するリング状の部品。布はすべてこれに貼る。首が回っても布が引っ張られない
- 布はほつれにくい薄手のちりめんか、100円ショップの和柄はぎれ。袖には接着芯を貼って張りを持たせ、切り口はほつれ止め液で処理する
- 袖は大きめに作り、畳台の上に広げて垂らすと平安らしいシルエットになる

**塞いではいけない場所**（チェックリスト）
- [ ] CoreS3 側面の電源ボタン
- [ ] USB-C 端子（給電と書き込み）
- [ ] スピーカー穴
- [ ] 画面上部のカメラと近接センサ ← **ここが隠れると御簾の演出が動かない**
- [ ] 首の回転範囲（襟と頭の間に 5mm 以上の隙間）
- [ ] お辞儀したときに烏帽子が文机や屏風に当たらないこと

### 2-4. 檜扇（ひおうぎ）
- 閉じた状態で 30×8mm、または 60° ほど開いた形。ヒノキの薄板か、木目調PLAで作る
- **男性用の檜扇は飾りなしの白木**が基本。女性用は飾り糸や造花を付ける。文麿は男性の従者なので白木にする
- 右の袖口に固定する（両面テープかピン）

印刷の分割：天板／胴／脚（胴と一体でも可）。印刷サイズが大きい天板は斜めに置くか、2分割にする。

### 3-2. 硯箱と筆（小物）
- 硯箱：30 × 22 × 6mm、黒＋金線。フタを少しずらして硯を見せる
- 筆：竹串を 25mm に切り、先に黒い糸の束を付ける
- 置く場所は文机の横。「ここで書いている」ことが一目で伝わる

### 3-3. 畳台
| 項目 | 仕様 |
|---|---|
| 外形 | 210 × 140 × 30mm |
| 中身 | CoreS3 用のモバイルバッテリーと配線（内寸の高さは 25mm を確保） |
| 本体 | 5mm 厚の MDF で箱を組む。上面に畳柄のシートを貼る |
| 縁（へり） | **高麗縁（白地に黒の紋）を推奨** |

> 時代考証メモ：畳の縁の柄は座る人の身分を表した。**繧繝縁（うんげんべり）は天皇や神仏級の最上位**で、高麗縁はそれに次ぐ高位の柄。文麿は従者なので繧繝縁は格が高すぎる。品よくまとめるなら高麗縁、見た目の華やかさを優先するなら繧繝縁も「あり」。

- 縁は、柄を紙に印刷して布用の両面テープで巻くのが一番手軽
- 100円ショップの「ミニ畳」（飾り台）が見つかれば、それを上に載せるだけでもよい

### 3-4. 屏風（四曲一隻）
| 項目 | 仕様 |
|---|---|
| 外形 | 1面 55 × 200mm を4面、合計の幅 約220mm |
| 地 | 胡粉白〜生成り。**金屏風にはしない**（桃山時代以降の記号になるため） |
| 表の絵 | 大和絵風の**すやり霞**（横長の雲の帯）と遠くの山並み。中央に「一句 賜ります」と大きく書く |
| 端 | ゲーム名とサークル名を小さく |
| 裏（スタッフ側） | 紙交換の手順、スマホ入力画面の QR、トラブル時のメモ |
| 作り方 | 3Dプリントの枠に厚紙を貼る。季節品の100円ショップ「ミニ屏風」を流用できればそれでもよい |

ケーブルは屏風の裏を通して隠す。

## 4. 短冊デザイン（印刷物）

### 4-1. 寸法
- 本物の短冊は**約 6 × 36cm**。S1 の紙は 57mm 幅なので、**幅は本物とほぼ同じ**になる
- 長さは**半分の 18cm**を推奨（紙の節約と持ち帰りやすさ）。36cm のフルサイズは特別賞用にする
- 印字幅は 384 ドット（48mm）。203dpi は 1mm あたり約8ドットなので、18cm ≒ **1440 ドット**

### 4-2. レイアウト（384 × 1440 ドット）
| y 範囲（ドット） | 内容 |
|---|---|
| 0〜120 | **打曇（うちぐもり）**風の帯。本物は上が藍、下が紫の雲形を漉き込んだ紙。白黒なので網点の濃淡で表現する |
| 140〜1100 | 句を**一行書き**で中央に縦書き。明朝 40〜44px。上五・中七・下五の間に小さな空きを入れる |
| 1120〜1260 | 詠み人の名前。左下に寄せて 28px |
| 1260〜1380 | **落款**：白抜きの角印 64×64（サークル名2文字）＋日付を小さく |
| 1380〜1440 | 打曇の下帯（薄め） |

- 俳句の短冊は一行書きが正統。三行に分けて書く散らし書きは和歌でよく使う形式なので、ここでは使わない
- フォントは LovyanGFX の `lgfxJapanMincho` 系
- 印刷の最後に、切り取り刃の位置まで余白を送る
- シール紙のときは「手帳やスマホに貼れる短冊」として案内する

### 4-3. 特別版（任意）
- 高得点の句：36cm のフルサイズ ＋ 金銀砂子を散らした風の網点柄
- 季節版：打曇の代わりに桜や紅葉の透かし柄

## 8. 製作順序
1. **S1 の実測**（排紙口の位置、フタの開き方、端子とランプの位置）
2. 文机カバーの試作 → 紙の通り道と切り取りやすさを確認
3. 烏帽子の試作 → 重量を量り、お辞儀の動作テスト
4. 顔（Avatar）のデザイン実装
5. 肩ヨークと装束
6. 畳台・屏風・小物
7. 通しリハーサル（30分連続で動かし、紙交換を1回行う）
8. 運搬箱（100円ショップの木箱を桐箱風に）と予備部品の準備
